# SPEC_007: CLI 기능 갭 분석

> **Claude Code CLI vs Kent 에디터 — 기능 비교 및 미구현 기능 목록**

---

## Overview

Claude Code CLI(터미널)가 제공하는 기능 대비 Kent 에디터(VS Code 포크)에 **없는 기능**과 **추가하면 좋을 기능**을 정리한 문서.

---

## 5. 현재 `/` 명령어 구현 방식 참고

**파일**: `browser/views/ui/claudeAutocomplete.ts`

현재 슬래시 명령어는 **프롬프트 삽입 방식**으로 동작:
- `/explain` → `"Explain this code in detail:"` 텍스트 삽입
- 실제 Claude CLI의 `/clear`, `/compact` 등과는 다른 메커니즘

새 명령어 추가 시 두 가지 방식 가능:
1. **프롬프트 삽입형** — 기존 방식, 텍스트만 바꿔서 전송 (`/review`, `/help`)
2. **액션 실행형** — 직접 서비스 메서드 호출 (`/clear`, `/compact`, `/cost`, `/model`)

`handleCommandItem()`에서 분기 처리 필요.
